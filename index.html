How to compare

Comparison toggles (all off by default)

The report always shows both raw values and records which toggles were on. Your files are never modified.

Map unmatched columns (optional)

These are guesses. Nothing is mapped until you choose it here.

Export the report

Paste it into a PR or an issue. It contains the differences — row and cell values included — so review it before sharing if the data is sensitive.

SheetDiff never uploads your files — there is no server, no analytics, and no network calls at runtime. Source on GitHub (MIT).
